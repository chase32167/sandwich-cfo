Как правильно купить б/у сэндвич-панели
✅
Когда б/у — отличный выбор
Гараж, навес, хозпостройка, временное сооружение. Не нужен сертификат и новый вид. Экономия 40–70% реальна.
❌
Когда б/у не подходит
Крупный объект от 500 м² — нет нужного объёма одного размера/цвета. Пищевое производство, медицина — нужны сертификаты.
🔍
Что проверить при покупке
Геометрию замков (деформация = сквозняки), состояние покрытия (коррозия), торец панели (намокание утеплителя), реальные размеры по факту.

Логистика
Уточняйте длину панелей — стандарт 6 м, но бывают 3 м и нестандарт. Длинные требуют спецтранспорт от 8 000 ₽/рейс по МО.

Ищите «неликвид», «остаток», «демонтаж» — это самые дешёвые варианты. Торгуйтесь при объёме от 30 м² — скидка 10–20% реальна.

Политика конфиденциальности и обработки персональных данных

1. Общие положения

Настоящая политика конфиденциальности определяет порядок обработки персональных данных пользователей сервиса «Аналитика рынка сэндвич-панелей ЦФО» (далее — Сервис), расположенного по адресу sandwich-cfo.vercel.app.

Используя Сервис и заполняя форму запроса анализа, вы выражаете согласие с условиями настоящей Политики конфиденциальности.

2. Состав персональных данных

Сервис собирает следующие персональные данные, добровольно предоставленные пользователем при заполнении формы: фамилия, имя, отчество; номер телефона; адрес электронной почты.

Загружаемые файлы (спецификации, коммерческие предложения) используются исключительно для выполнения запрошенного анализа и не сохраняются на серверах после обработки.

3. Цели обработки персональных данных

Персональные данные обрабатываются в следующих целях: предоставление услуги анализа коммерческих предложений; подготовка сравнительных отчётов по ценам поставщиков; обратная связь с пользователем по результатам анализа.

4. Правовое основание обработки

Обработка персональных данных осуществляется на основании согласия субъекта персональных данных (ст. 9 Федерального закона № 152-ФЗ «О персональных данных» от 27.07.2006).

5. Порядок обработки и хранения

Сбор персональных данных осуществляется через защищённое соединение (HTTPS). Данные передаются на сервер для выполнения анализа и не сохраняются в базах данных Сервиса. Загружаемые файлы обрабатываются в оперативной памяти сервера и удаляются сразу после формирования ответа.

6. Передача третьим лицам

Для формирования аналитического отчёта Сервис использует API Anthropic (claude.ai). Текст передаваемых данных обрабатывается в соответствии с политикой конфиденциальности Anthropic (anthropic.com/privacy). Персональные данные пользователей не передаются иным третьим лицам без согласия субъекта, за исключением случаев, предусмотренных законодательством РФ.

7. Права субъекта персональных данных

Вы вправе: получить информацию об обработке ваших персональных данных; потребовать уточнения, блокирования или уничтожения персональных данных; отозвать согласие на обработку персональных данных.

Для реализации указанных прав направьте запрос по адресу электронной почты, указанному в разделе «Контакты».

8. Защита данных

Сервис принимает организационные и технические меры для защиты персональных данных от неправомерного доступа, изменения, раскрытия или уничтожения. Соединение с Сервисом защищено протоколом TLS/SSL.

9. Изменение политики

Сервис оставляет за собой право вносить изменения в настоящую Политику конфиденциальности. При существенных изменениях актуальная версия публикуется на данной странице.
