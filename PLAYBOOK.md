## 0. СТРУКТУРА ПРОЕКТА

```
D:\Projects\sandwich-cfo\
├── index.html        — единый файл дашборда (все данные встроены)
├── suppliers.js      — база поставщиков (справочник, не подключён к HTML)
├── avito-data.js     — 50 объявлений Авито (справочник)
├── avito-live.js     — живые данные Авито (устаревший формат)
├── CONTEXT.md        — база знаний: 30 поставщиков, параметры панелей
└── PLAYBOOK.md       — этот файл
```

**Важно:** index.html содержит ВСЕ данные inline (suppliers[], avitoItems[]).
suppliers.js и avito-data.js — справочники/бэкапы, не `<script src>`.

## 1. ДОБАВЛЕНИЕ НОВОГО ТИПА МАТЕРИАЛА (например, профлист, утеплитель)

### Шаг 1 — Создать новый файл данных
```
D:\Projects\sandwich-cfo\<material>-suppliers.js
```
Структура объекта поставщика:
```js
{
  name: 'Название компании',
  url: 'https://site.ru/',
  city: 'Москва',
  region: 'Москва',           // 'Москва' | 'МО' | 'Воронеж' | 'Тула' | 'Липецк' | ...
  types: ['Тип1', 'Тип2'],    // типы продукции
  price: 1500,                // цена от, руб/м² (число)
  minOrder: 'от 1 м²',
  rating: 4,                  // 1–5
  status: 'Производитель',    // 'Производитель' | 'Поставщик' | 'Дилер'
  bu: false,                  // true если продают б/у
  buNote: '',                 // пояснение если bu:true
  note: 'Краткое описание'
}
```

### Шаг 2 — Добавить секцию в index.html
Найти раздел с нужным материалом или создать новый `<section>` по образцу секции "Поставщики".
Добавить:
- Заголовок секции
- Filter-row с select'ами (тип, регион, статус)
- Таблицу `<table>` с `<tbody id="<material>Body">`
- Toggle "Скрыть б/у" (если актуально)

### Шаг 3 — Добавить JS в index.html
```js
// Массив поставщиков (можно встроить или вынести в отдельный .js)
const <material>Suppliers = [...];

// Рендер строк таблицы
function render<Material>Table(data) { ... }

// Фильтрация
function filter<Material>Table() { ... }

// Инициализация
render<Material>Table(<material>Suppliers);
```

## 3. ДОБАВЛЕНИЕ АВИТО-ОБЪЯВЛЕНИЙ

### Шаг 1 — Сбор данных через Chrome MCP
```js
// Открыть в Chrome: avito.ru/moskva/remont_i_stroitelstvo/...?q=<материал>
// Выполнить через javascript_tool (НЕ через консоль вручную):
document.querySelectorAll('[data-marker="item"]').length
// Если >0 — собрать данные
```

### Структура объекта Авито
```js
{
  title: 'Название объявления',
  price: '1 500 ₽',    // строка
  priceNum: 1500,       // число для сортировки
  condition: 'Новые',   // 'Новые' | 'Б/у'
  panelType: 'Стены',   // 'Стены' | 'Кровля' | 'Стены+Кровля'
  insul: 'ППС',         // тип утеплителя / материала
  thick: '100 мм',      // толщина / размер
  size: '1190×6000 мм', // габариты
  city: 'Москва',       // город
  date: 'апр 2026',     // дата объявления
  href: 'https://www.avito.ru/...' // ссылка (без query params)
}
```

### Шаг 2 — Обновить avitoItems в index.html
Найти `const avitoItems=[` и заменить весь массив Python-скриптом:
```python
with open('index.html', 'r', encoding='utf-8') as f:
    content = f.read()
# найти old_start/old_end границы массива
# вставить новый массив
```

### Шаг 3 — Обновить avito-data.js (справочник)
Тот же массив, но с переменной `avitoData` вместо `avitoItems`.

### Что собирать с каждого поставщика
- Название компании
- Город / регион ЦФО
- Типы панелей / материалов
- Цена от (руб/м² или руб/шт)
- Сайт компании
- Контакт (телефон или email)
- Статус (производитель / дилер / поставщик)

### Алгоритм проверки на дубль
```
1. Сравнить name с существующими suppliers[].name
2. Сравнить url (domain) с существующими suppliers[].url
3. Сравнить city + типы продукции
→ Если всё новое → добавлять
→ Если совпадает хоть одно → пропустить
```
